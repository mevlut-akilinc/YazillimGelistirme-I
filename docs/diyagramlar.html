04-sequence-login.mmd

Sequence: öğrenci girişi

Ogrenci.exe veritabanını bilmez; numara ve şifre Egitmen.exe'deki sunucuda doğrulanır.

sequenceDiagram
    autonumber
    actor O as Öğrenci
    participant UI as Ogrenci.exe · LoginWindow
    participant VM as LoginViewModel
    participant C as Ogrenci.exe · ExamClient
    participant S as Egitmen.exe · ExamServer
    participant A as Egitmen.exe · Şifre kontrolü
    participant DB as PostgreSQL (localhost)

    O->>UI: Rol=Öğrenci, numara, şifre, sunucu IP
    UI->>VM: LoginCommand
    VM->>VM: Alanları doğrula (boş mu, IP geçerli mi)
    VM->>C: ConnectAsync(ip, 5050)
    C->>S: TCP bağlantısı
    S-->>C: Bağlantı kabul
    C->>S: LOGIN {numara, şifre, rol}
    S->>S: Bu numara başka PC'de açık mı?
    S->>A: Doğrula(numara, şifre)
    A->>DB: SELECT password_hash, role FROM users WHERE username=?
    DB-->>A: kayıt
    A->>A: Şifre hash karşılaştır (BCrypt)
    alt Bilgiler doğru
        A-->>S: Session(token)
        S->>DB: INSERT INTO logs (bağlandı)
        S-->>C: LOGIN_OK {token, ad soyad}
        C-->>VM: Session
        VM-->>UI: LoginSucceeded
        UI->>UI: StudentWindow aç (bekleme ekranı)
    else Hatalı
        A-->>S: null
        S-->>C: LOGIN_FAIL
        C-->>VM: null
        VM-->>UI: "Kullanıcı adı veya şifre hatalı"
    end
05-sequence-exam.mmd

Sequence: sınav dağıtımı ve cevap toplama

Cevapsız sınav gönderimi, öğrencide yerel derleme, sunucuda süre kontrolü, puanlama ve log.

sequenceDiagram
    autonumber
    actor E as Eğitmen
    participant EU as Egitmen.exe · Arayüz
    participant S as Egitmen.exe · ExamServer
    participant DB as PostgreSQL
    participant C as Ogrenci.exe (n adet)
    actor O as Öğrenci

    E->>EU: Sunucuyu başlat
    EU->>S: StartAsync(5050)
    S->>DB: INSERT log "sunucu açıldı"
    C->>S: Bağlan + LOGIN
    S-->>EU: StudentConnected (canlı liste)
    E->>EU: Sınavı seç → Dağıt
    EU->>S: BroadcastExamAsync(exam)
    S->>DB: UPDATE exams SET status='YAYINDA', started_at=now()
    par Tüm bağlı öğrencilere eş zamanlı
        S->>C: EXAM {StripForStudent: cevap anahtarı ve gizli testler hariç}
    end
    C-->>O: Sınav ekranı + geri sayım
    loop Sınav süresince
        O->>C: Cevap seç / yaz
        opt Kodlama sorusu
            C->>C: gcc ile derle, görünür testleri çalıştır
            C-->>O: Hata veya geçen test sayısı
        end
        C->>S: PROGRESS {cevaplanan sayısı}
        S-->>EU: StudentChanged
    end
    O->>C: Sınavı bitir ve gönder
    C->>S: SUBMIT {examId, cevaplar}
    S->>S: now() <= bitiş zamanı mı?
    alt Süre içinde
        S->>S: Cevap anahtarı ile puanla (ÇS, klasik)
        S->>S: Kodlama: gcc ile TÜM testler + karmaşıklık ölçümü (kuyrukta)
        S->>DB: INSERT submissions, answers
        S->>DB: INSERT log "teslim etti" (tarih-saat, IP)
        S-->>C: SUBMIT_OK
        C-->>O: "Sınav teslim edildi"
    else Süre doldu
        S->>DB: INSERT log "geç gönderim reddedildi"
        S-->>C: SUBMIT_REJECTED
    end
    E->>EU: Sonuçlar
    EU->>DB: Öğrenci bazlı puanlar + sınıf ortalaması

Akış diyagramı: sunucuda puanlama ve karmaşıklık

flowchart TD
    A([Egitmen.exe: teslim edilen kod kuyruktan alındı]) --> B["gcc -std=c11 -O0 main.c -o prog<br/>(zaman aşımı: 10 sn)"]
    B --> C{Derlendi mi?}
    C -- Hayır --> C1[Derleyici çıktısını döndür<br/>puan = 0] --> Z([Bitti])
    C -- Evet --> D[Gizliler dahil her test case için<br/>stdin ver, stdout karşılaştır<br/>süre limiti: 2 sn]

    E --> F["Girdi boyutları üret<br/>n = 1k, 2k, 4k, 8k, 16k, 32k"]
    F --> G["Her n için programı 3 kez çalıştır<br/>medyan süre t(n) ve<br/>tepe bellek m(n) ölç"]
    G --> H["log t(n) – log n doğrusal regresyon<br/>eğim k ≈ büyüme derecesi"]
    H --> I{"Aday modellerle uyum<br/>1, log n, n, n log n, n², n³, 2ⁿ<br/>en yüksek R² olan"}
    I --> J[Zaman karmaşıklığı]
    G --> K["Aynı yöntem m(n) için"]

    N --> Q
    O --> Q
    P --> Q
    Q["Soru puanı = P × (w_test × geçen/toplam<br/>+ w_karm × karmaşıklık puanı)"]
